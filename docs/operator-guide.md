# Guía de operación

## Supervisor

1. Cree la campaña y seleccione zona horaria/contexto saliente.
2. Importe un CSV, asigne ID, nombre, teléfonos y campos adicionales; revise errores.
3. Verifique el mapa usuario/agente/extensión.
4. Previsualice la asignación y confirme la cantidad.
5. Supervise pendientes, callbacks, resultados y llamadas rechazadas.

## Agente

1. Inicie sesión en Issabel y abra **Gestión de Clientes > Mi cartera**.
2. Tome el siguiente cliente. Los callbacks vencidos y del día aparecen primero.
3. Elija un teléfono y pulse **Llamar**; conteste Zoiper para iniciar el tramo cliente.
4. Al terminar, guarde resultado y nota. Para callback indique fecha, hora y zona.
5. Pruebe otro número si corresponde; avance solo después de guardar.

Si el sistema informa mapeo inexistente/ambiguo, intento activo o estado sin
reconciliar, no repita llamadas: contacte al supervisor con el `request_id`.
